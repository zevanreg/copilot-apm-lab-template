# Reviewable learner evidence

Copy [the template](TEMPLATE.md) to `submission.md` during setup. Commit the
completed submission with your learner branch.

Keep evidence concise but specific: command, actual outcome, source/artifact
identity, and a short explanation. Do not paste entire chats, private payloads,
tokens, tenant details, personal information, or unrelated internal URLs.

APM checks, application tests, Copilot discovery observations, and Azure UI/build
evidence answer different questions. Do not substitute one for another.

An unavailable hosted environment must be marked pending or blocked. A local
success does not establish a required Azure Repos PR policy.
